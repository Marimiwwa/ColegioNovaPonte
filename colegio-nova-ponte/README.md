# Colégio Nova Ponte

Homepage institucional responsiva de uma escola fictícia, criada como teste técnico para a vaga de **Desenvolvedora Web Júnior**.

Feita com **HTML, CSS e JavaScript puro**, sem frameworks.

**Site no ar:** `https://SEU-USUARIO.github.io/colegio-nova-ponte`

## Destaques

- Carrossel de slides com destaque para matrículas e CTAs
- Seções de O Colégio, Segmentos de Ensino, Ensino Médio, Diferenciais e Atividades Extracurriculares
- Barra superior com telefone, redes sociais e bandeiras de idiomas (Português, Inglês e Espanhol)
- Formulário de contato com máscara de telefone, validação em JavaScript e mensagem de confirmação
- Rodapé completo e botão flutuante de WhatsApp
- Layout responsivo para **mobile, tablet e desktop**
- Identidade visual própria em turquesa e amarelo, com logo em SVG

## Como executar

Abra o `index.html` no navegador. Não precisa instalar nada.

As fontes (Sora e Inter) vêm do Google Fonts. Sem internet, o site usa fontes do sistema.
